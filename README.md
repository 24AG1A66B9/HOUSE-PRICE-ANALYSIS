# 🏠 House Price Analysis & Prediction

A Machine Learning project that analyzes housing data, explores the factors affecting house prices, and predicts house prices using multiple regression models.

## 📌 Project Overview

This project performs data cleaning, exploratory data analysis, visualization, feature preparation, and machine learning-based house price prediction.

The project analyzes how different property features influence house prices and compares multiple regression models using standard evaluation metrics.

The application is built using **Python, Pandas, Matplotlib, Seaborn, Scikit-learn, and Streamlit**.

---

## 🎯 Objectives

- Clean and preprocess housing data
- Handle missing values
- Detect and handle outliers
- Perform exploratory data analysis
- Visualize relationships between property features and prices
- Encode categorical variables
- Select meaningful features
- Build multiple regression models
- Compare model performance
- Predict house prices
- Identify important features influencing house prices
- Generate useful observations and insights

---

## ✨ Features

### 🧹 Data Cleaning
- Missing value detection
- Missing value handling
- Duplicate removal
- Numerical and categorical data processing
- Outlier handling using the IQR method

### 📊 Exploratory Data Analysis

The application provides visualizations such as:

- House price distribution
- Feature vs house price analysis
- Categorical feature analysis
- Correlation heatmap
- Actual vs predicted prices

### 🤖 Machine Learning

The project compares multiple regression models:

1. **Linear Regression**
2. **Random Forest Regressor**
3. **Gradient Boosting Regressor**

### 📈 Model Evaluation

Models are evaluated using:

- MAE — Mean Absolute Error
- MSE — Mean Squared Error
- RMSE — Root Mean Squared Error
- R² — R-Squared

### ⭐ Feature Importance

Tree-based models are used to identify the most influential features affecting house prices.

### 💡 Insights

The application provides observations about:

- Average house price
- Minimum and maximum prices
- Strong relationships between numerical features and price
- Best-performing machine learning model
- Most influential features
